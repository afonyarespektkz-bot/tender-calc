# ИИ-менеджер TenderMax — стенд для обкатки

Речь клиента → **K5** (распознавание казахского/русского, работает локально) → **Claude** (ответ) → **MMS** (озвучка kk/ru, локально).
Открывается в браузере: можно «позвонить» боту, говорить в микрофон или писать реплики клиента текстом.

## Запуск на Windows-ноутбуке с видеокартой NVIDIA
1. Скачайте папку `ai-caller` (GitHub → Code → Download ZIP, распаковать).
2. Запустите `setup.bat` (один раз, ~15–30 минут: ставит Python, ffmpeg, библиотеки и скачивает модели ~2.6 ГБ).
3. Создайте в папке файл `.anthropic_key` и вставьте туда ключ Claude (`sk-ant-...`).
4. Запустите `run.bat` — откроется http://localhost:8800.

## Файлы
- `prompt.md` — правила поведения бота.
- `offer.md` — **предложение недели** (даты вебинаров, цены, акции). Меняется каждую неделю.
- `server.py` — сервер; `index.html` — страница обкатки.
- Разговоры сохраняются в `sessions/`.

Ключ, модели и записи разговоров в репозиторий не попадают (`.gitignore`).
